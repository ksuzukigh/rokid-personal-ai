# 私のAI：自由な会話と確認後の実作業

第1段階は、利用者の一回の自由な依頼を固定コマンドや固定分類へ当てはめず、その目的を理解して短い答えを一つ返す。

利用者が選ぶ機能メニューはない。たとえば個人資料の確認とWeb情報の確認が一つの依頼に必要なら、個人AIがその都度必要な読み取り手段を組み合わせる。

## 現在つながっている範囲

現在の`one-turn-agent.mjs`は、ChatGPTログインのCodex CLIとGPT-5.6 Lunaを使って一回の自由な発言を処理する既存経路である。Google Driveの読み取り専用参照またはWeb検索を必要に応じて使えるが、直前1往復だけを渡す構造と操作種別の列挙は移行前の実装であり、ここへ新しい操作を追加し続けない。

2026-08-26以降は、利用者が質問・依頼を区別せず話し、AIが必要なら自ら聞き返し、返答後も同じCodex作業セッションを再開する一般会話を中心にする。画面と会話記録は`私：` / `AI：`を使う。AIの意味理解、調査、計画、聞き返しを固定分類で狭めず、現実への効果の直前だけ対象・内容・権限・利用者確認を共通境界で検証する。

`codex-conversation-session.mjs`は、その新設計のMac側会話部品である。初回のCodex JSONイベントから作業セッションIDを得て、次の発言を`codex exec resume`で同じセッションへ送る。出力は利用者へ返す発言、追加情報の要否、許可済み範囲の構造化候補である。Codexは利用者設定を読み込まず、読み取り専用で起動し、Computer Historyと読み取り専用Web検索だけを検証済み実体へ再接続する。会話終了時に保存セッションを削除する。現在は`one-turn-voice-relay.mjs`の日常音声受け口と、Mac側の共通確認境界に接続済みである。

共通境界へ渡せる候補は、Obsidian固定保存先への新規Markdown、Obsidian保管庫内の既存Markdownの一箇所置換、Google Drive固定フォルダへの新規Googleドキュメントの3種類だけである。Rokidは対象と内容を表示し、別の1回操作後だけ短命・一回限りの確認券を渡す。機能別URLはAIXへ戻さず、`/v1/confirm-effect`と`/v1/cancel-effect`だけを使う。送信、公開、共有、削除、移動、任意保存先、Drive既存文書編集は未接続である。

第3段階では、Obsidian専用保存先への新規Markdown文書1件、同じ保存先にある既存Markdown文書への末尾追記、Google Drive専用フォルダへの新規Googleドキュメント1件を扱う。0.21.0では、Obsidian文書の読み取り専用検索・要約と、文書名・現在文・変更後文が一意な場合の一箇所変更まで実機合格した。「その文書」のような省略を固定規則で展開せず、Lunaが元の依頼、直前の会話、許可済みの実文書候補と抜粋を一緒に考え、対象と変更箇所を選ぶ。AIは変更前候補を作るだけで、Rokidが対象と内容を表示し、別の1回確認を受けた後に限り反映する。確認中に文書が変わった場合は反映しない。文書全体の書き直し、文の削除、移動、共有、送信、公開はまだ行わない。通常回答はRV101で読める240文字以内とする。

`new-document-action.mjs`は、「私のAI 作成文書」のみを人が読める保存先名として許可する。新規作成では題名と全文、追記では実際の題名・追加本文・候補時点の文書内容ハッシュを確認券と一体で検証し、確認後15秒以内の一回だけ実行する。シンボリックリンクで別場所へ出る保存先も拒否する。保存・追記・対象変更による停止・取消・失敗の結果は、会話本文と別の「実行結果」として日付別会話記録へ残す。

`google-drive-action.mjs`は、Drive内の固定フォルダ`Rokid/私のAI 保存文書`だけを対象にする。通常の「Google Driveへ保存」はネイティブGoogleドキュメントを意味し、Markdownを既定にしない。確認済み候補と一致する題名・本文を一件作り、作成ID、フォルダ一覧、Google Docs本文の読み戻しが一致した時だけ成功とする。

`one-turn-session-receiver.mjs`は、一回の依頼を受けるMac側の入口である。32バイト以上の使い捨て認証、最長10分の期限、一回消費、取消、2KB本文上限を持つ。`127.0.0.1`だけで待ち受け、固定名への接続は試行中だけ開く。

`prepare-one-turn-aix.mjs`は、録音なしの指定文字一件を送り、Macが返した回答をRV101へ表示する一時AIXを作る。分類名や内部の道具名は表示しない。変更なし・一時処理と確認できない応答は採用しない。

`start-fixed-one-turn-session.mjs`は、Mac側の入口、短時間の固定接続、一時AIXを同じ使い捨て認証で準備する。成功、取消、失敗、期限切れのいずれでも接続と一時ファイルを終了する。

`personal-ai-mac-service.mjs`は、RV101で「私のAI」が開かれたことを独立して待ち受ける。起動合図を受けると、固定接続と別名の一時AIXを準備して「どうぞ」画面を開く。ここではまだ録音せず、終了時は通信情報なしAIXで実行キャッシュを消して一時AIXを削除する。

`daily-one-turn-voice-session.mjs`は、自由な音声発言の既存受け口を日常入口へ接続する。AI画面の「続けて話す」で入力へ戻り、次の発言を同じCodex作業へ送る。文字化した利用者の発言とAIの応答はObsidianの日付別会話記録へ`私` / `AI`として自動追記する。原音と一時WAVは保存しない。

`mac-companion/install-service.mjs`を一度実行すると、Macログイン時に専用待受けだけが起動する。録音やCloudflare接続は常時起動せず、Rokidで「私のAI」を開いた一回だけ準備する。

## 検証済み

- 一般会話からObsidian新規文書候補を表示し、ダブルタップでは取消・ファイル0件、別の通しの1回確認後だけ0600のMarkdown一件を作るRV101実機経路に合格した。
- 同名作成は1件だけで、確認前・取消・二重実行・対象変更・曖昧な編集・期限切れを無変更で閉じる全218自動検査に合格した。

- バックグラウンドの個人AIからGoogle Driveを読み取り専用で参照できる。
- 自由な依頼一件から回答一件を返せる。
- 固定接続を通した一往復で、読み取り、回答、変更0件、一時処理を確認した。
- 通常アプリ入口から録音なしで準備画面と質問画面を実機表示した。
- Mac専用待受けのログイン時自動起動、終了後の一時AIX・受け口・接続0件を確認した。
- Google Driveの専用フォルダへ、確認後だけネイティブGoogleドキュメントを一件作成し、作成ID、一覧、本文の読み戻し、会話記録まで実機で確認した。
- 同じ起動中に対象文書を要約し、次の「その文書」という依頼で正しい現在文と変更後文を表示、別の1回確認後だけ実文書の一箇所を変更する経路に実機合格した。
- 自動検査208件と構文検査に失敗0。Android起動役は0.16.9、versionCode 25、要求権限0のまま変更していない。

## 実機確認済み

1. Rokid上の二段階操作で1問目を録音し、361,600バイトを受信して22.095秒で回答した。
2. 回答画面の「もう一度質問」を1回操作し、「質問できます」へ戻った。
3. アプリを開き直さず2問目を録音し、345,600バイトを受信して29.674秒で回答した。
4. 終了後は2問処理済みの待受けを閉じ、一時AIX、Mac一時フォルダ、18448番受け口、関連トンネルを残さず、消灯5秒へ戻した。

自由な一質問への実経路と、同じアプリ起動中に前の質問を引き継がない次の一問一答へ戻る操作は合格済み。外部への作成・保存・送信、長時間作業は後の段階で能力を追加する。

0.17.0では、上の合格済みの連続質問入口へ、直前1往復だけの短期会話記憶と、Obsidianの日付別会話記録を接続する。メモリー上の文脈は新しい話題に使わず終了時に破棄する一方、文字の質問と回答は後から読める個人記録として残す。原音と一時WAVは残さない。

RV101実機の同一起動3問で、初回参照なし、追加質問は参照あり、新規話題は参照なしとなることに合格した。各3件を実の日付別会話記録へ追記し、モード0600。終了後は一時ファイル、受け口、トンネル接続が0、消灯5秒。全168検査と構文検査に合格した。

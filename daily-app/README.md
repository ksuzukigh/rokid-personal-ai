# 私のAI 通信なし準備画面

普段のアプリ一覧に表示される入口は、`daily-launcher-android`のAndroidアプリが担当します。このAIXは、質問セッション終了時に一時AIXの実行キャッシュを通信情報なしの内容へ戻すために使います。

固定メニューや分類は表示しません。「私のAI」を開くと、Mac側が一回限りの質問経路を安全に準備し、準備が整った後だけ自由に一つ質問できます。

このAIX自体は録音、通信、保存、外部操作を行いません。YodaOSのアプリ一覧へ登録せず、固定の日常起動ファイルとしても置きません。

専用アイコンはAndroid起動役が表示します。この後片付け用AIXにはアイコン画像を重複して含めません。

```sh
node build-aix.mjs /tmp/rokid-personal-ai-daily.aix
```

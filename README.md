# Rokid Personal AI（私のAI）

Rokid AI Glassesは、マイクとディスプレイを備えたスマートグラスです。

「私のAI」は、Macでいつも使っているChatGPTデスクトップアプリを、Rokidから使えるようにしたものです。ChatGPTからは、Obsidianに保存したメモや資料、Google Driveにある文書も利用できます。

Rokidで話した内容はMacへ送られ、ChatGPTの答えがRokidのディスプレイに表示されます。前のやり取りを踏まえながら、そのまま会話を続けられます。

このリポジトリでは、実際に使っている仕組みから個人情報や接続情報を取り除き、同じようなものを自分で作りたい人が参考にできる部分を公開しています。完成品やインストーラーを配布するものではありません。

## できること

- 眼鏡のマイクを使って、AIと日本語で会話する
- 前のやり取りを踏まえて、そのまま話を続ける
- Webを調べる
- AIとのやり取りをObsidianに日付別で残し、Web検索で得たURLなどをあとからMacで確認する
- 自分のObsidianにある文書を探し、内容をもとに答える
- 内容を確認してから、Obsidianに文書を作る
- 内容を確認してから、Obsidianの既存文書の一部を直す
- 内容を確認してから、指定したGoogle Driveフォルダに文書を作る
- スマートフォンのテザリングを使い、外出先でもMac上のAIと会話する

質問や調査は、普段の言葉で頼めます。「これは質問」「これは保存」といったメニューを先に選ぶ必要はありません。何を指しているのか分からないときは、AIが会話の中で聞き返します。

## 実際の使い方

1. Rokidに「Hi Rokid、私のAI」と話しかけます。
2. 「どうぞ」と表示されたら、テンプルを1回操作します。ここで録音が始まります。
3. 話し終わったら、もう一度操作します。
4. 眼鏡にAIの答えが表示されます。
5. 「続けて話す」を1回操作すると、前の会話を引き継いだまま次の録音が始まります。
6. 終了するときはダブルタップします。最初の1回で会話を閉じ、純正AIの案内画面を残さず終了します。

「私のAI」を開いただけでは録音しません。録音した音声と、文字起こしのために作った一時ファイルは、処理が終わると削除します。

利用時には、Macの電源が入り、利用者がログインした状態でインターネットへ接続され、ChatGPTデスクトップアプリと専用の待機プログラムが動いている必要があります。Macへ接続できない場合はRokidに接続できないことを表示し、録音は始めません。

## システムの仕組み

![RokidからMacへ音声を送り、WhisperとCodexで処理して、答えをRokidへ戻す流れ](docs/images/rokid-personal-ai-system.png)

図は全体の流れを示したものです。実際の通信先や認証情報は含めていません。

### 1. 「Hi Rokid、私のAI」と話しかけて開く

Rokidの音声呼び出し機能に、「私のAI」という呼び出し先を追加しています。「Hi Rokid、私のAI」と話しかけると「どうぞ」の画面が開きます。画面表示、テンプル操作、マイク録音はRokid側の機能を使います。

Rokidの開発資料では、この追加機能を「AIUI Agent」、作成画面を「AIUI Studio」、中で動くプログラムを「AIX」と呼びます。これは仕組みの名称で、利用するときに意識したり操作したりする必要はありません。

「私のAI」は開始時にMacへ安全に接続し、その会話だけに使う一時的な接続情報を受け取ります。Rokidのマイクで録音した音声をMacへ送り、音声の文字化とAIによる判断はMac側で行います。

終了時は、まずMacへ会話終了を知らせて一時接続を閉じ、その後に「私のAI」の会話画面と、呼び出し後にRokid側へ残る画面を順に閉じます。ここはRokid固有の処理を含むため、公開版では考え方と確認結果だけを説明し、実装は掲載していません。

### 2. Rokidで話す

Rokid AI Glasses RV101には、マイク、ディスプレイ、Wi-Fiがあります。

利用者の声はRokidのマイクで録音します。AIそのものがRokidの中で動いているわけではありません。録音した音声をWi-FiでMacへ送り、Macから返ってきた答えをRokidのディスプレイに表示します。

### 3. RokidとMacを通信させる

この仕組みを使うには、RokidとMacの間で通信できることが必要です。

同じ場所で使うときは、RokidをWi-Fiへ接続します。Macを自宅などに置いたまま外出先で使うときは、RokidのWi-Fi接続先をスマートフォンのテザリングへ切り替えます。Wi-Fiとテザリングは、どちらもRokidをネットワークへ接続するための方法です。

保存済みWi-Fiの切り替えをRokid単体で行いたい場合は、別アプリの [Wi-Fi Selector](https://github.com/ksuzukigh/rokid-wifi-selector) を利用できます。Hi Rokidで設定したアクセスポイントのうち、現在接続しているものと付近にある候補をRokidへ表示し、自宅などのWi-Fiとスマートフォンのテザリングを選んで切り替えられます。

ネットワークへ接続したRokidからMacへ到達するために、Cloudflare Tunnelのような仕組みで、認証付きのHTTPS通信経路を用意します。Wi-Fiやテザリングとは役割が異なり、本システムでは自宅でも外出先でも、このHTTPS通信経路を通してMacへ接続します。この公開版では通信先と認証情報を例示値に置き換えているため、使う人が自分の通信経路を準備する必要があります。

### 4. Macで音声を文字にする

MacではChatGPTデスクトップアプリを常時起動して運用します。Rokidからの通信は、Macで待機している専用プログラムが受け取ります。

届いた音声は、Mac上のwhisper.cpp（Whisper）で文字データに変換します。発話がないときに余分な文章を作らないよう、Whisperへ渡す前に音声の有無も判定します。録音と変換用の一時ファイルは、処理後に削除します。

### 5. Codexが依頼を処理する

文字にした利用者の発言を、ChatGPTデスクトップアプリに同梱されているCodex CLIへ渡します。本システムの作成者の環境では、AIモデルに **GPT-5.6 Luna** を指定しています。

本システムでは、ChatGPT Workで使うCodexに、ObsidianとGoogle Driveを利用するための接続を設定してあります。依頼に合うスキルがある場合は、スキルも利用できます。これは本システムの作成者が使っている構成であり、すべてのChatGPTアカウントやAIモデルで同じ動作を確認したものではありません。また、Rokidからの会話へすべての機能をそのまま渡すのではなく、必要な接続と操作だけを使えるようにしています。

Codexは利用者の発言と、それまでの会話を読んで、質問への回答、Web調査、Obsidianの検索、文書作成など、何を求められているのかを判断します。意味がはっきりしないときは、決めつけずにRokidへ聞き返します。

### 6. 答えをRokidへ戻す

Codexが作った答えは、RokidからMacへ音声を送ったときと逆の通信経路を通ってRokidへ戻り、ディスプレイに表示されます。

利用者が「続けて話す」を選ぶと、次の発言も同じCodexの会話へ渡すため、前の話を踏まえたやり取りを続けられます。

利用者が終了のダブルタップをすると、進行中の録音や未実行候補を取り消し、Mac側の会話終了を待ってから画面を閉じます。実機では、「私のAI」の画面や「スワイプでページ送り」と表示される画面が残らず、1回のダブルタップで終了することを確認しました。

### 7. 会話をObsidianに残す

利用者が話した内容とAIの答えは、Mac上のObsidianへ日付別のMarkdown文書として自動的に追記します。各記録には日本時間の時刻、`私:`と`AI:`の発言、直前の会話を参照したか、回答が完了しているか、それとも聞き返しの途中かを残します。

Web検索の回答にURLが含まれていれば、そのURLもAIの答えの一部として記録されます。眼鏡を外したあと、MacのObsidianで会話を読み返し、紹介されたページを開いて内容を自分で確かめられます。何を質問し、AIが何を答え、その後に何を保存・編集したかもたどれるため、AIの回答を鵜呑みにせず検証するための記録になります。

この会話記録だけは、別の保存依頼をしなくても決められたフォルダへ決められた形式で追記します。AIが保存先や書式を自由に選ぶことはできません。保存・編集を実行したときだけでなく、取り消したときや失敗したときの結果も記録します。録音した原音は会話記録へ入れず、処理後に削除します。一方、Obsidianの会話記録は自動では削除しません。保管する期間や削除の方法は、利用者自身で管理します。

### 8. 最低限の制限をかける

自然な質問や依頼の理解を、決まった言い方や固定メニューへ狭めない一方で、通信と保存・編集には次の制限をかけています。

- 「私のAI」を使い始めたときだけMacとの接続を作り、終了したら閉じる
- 接続するたびに新しい秘密の値を使い、別の接続から届いた要求は受け付けない
- 受け取るデータの大きさ、待ち時間、同時に動かす接続数を制限する
- AIとの会話部分は、固定した会話記録への追記を除いて読み取り専用で動かし、自由にファイルを書き換えさせない
- 会話記録は、決めたフォルダへ決めた形式で追記し、AIに保存先や書式を選ばせない
- 保存や編集は、対象と内容をRokidに表示し、利用者が別の1回操作をした後だけ実行する
- 現在許可している変更は、Obsidianへの新規文書作成、既存文書の一箇所編集、指定フォルダへのGoogleドキュメント作成に限る
- 送信、公開、共有、削除、移動、購入、予定登録などは、Rokidから自由に実行できない

## 保存や編集を頼んだとき

日付別の会話記録への自動追記を除き、AIが勝手に文書を作ったり、書き換えたりすることはありません。

たとえば「この内容をObsidianへ保存して」と頼むと、眼鏡に次の内容が表示されます。

- 保存先
- 文書の題名
- 保存する本文
- 「まだ保存していません」という案内

内容を見て、別の1回操作をしたときだけ、その文書を1件作ります。取り消したとき、時間切れになったとき、確認後に内容や保存先が変わったときは、何も変更しません。

既存文書の編集やGoogleドキュメントの作成も、同じ手順です。文書を実際に保存・編集する直前は、人が内容を確認して決めます。

## このままでは使えません

このリポジトリには、次のものを入れていません。

- インストーラー
- インストール用APK
- 実際に使っている「私のAI」のプログラムと登録設定
- Rokid固有の終了処理と、そのための権限設定
- 本システムの作成者が使っている通信先や認証情報
- ObsidianとGoogle Driveの実データ
- 録音、会話記録、実機画像
- 本システムの作成者のMacに合わせたパスや個人設定

つまり、ダウンロードしてボタンを押せば使えるアプリではありません。Rokid、Mac、通信経路、保存先を自分の環境に合わせて組み直し、自分で検証できる方を対象にしています。

この仕組みは、使う人ごとに資料、保存先、許可する操作が違います。そのため、共通のインストーラーは用意せず、設計とコードだけを公開しています。

## 自分で作ってみたい方へ

再現には、少なくとも次の環境と作業が必要です。

- Hi Rokidで開発者モード（ADB）を有効にしたRokid AI Glasses RV101
- Rokid開発用5ピンUSBケーブル（初回のアプリ導入と動作確認に使用。付属の3ピンUSBケーブルは充電用のため、Macとの接続には使えません）
- macOSを搭載したMac
- Node.jsとAndroidの開発環境
- ChatGPTデスクトップアプリと、ChatGPTへログイン済みのCodex CLI
- Macで動かすWhisperと音声判定モデル
- Cloudflare Tunnelなど、自分で管理するHTTPS通信経路
- 自分のObsidian保管庫と、必要に応じてGoogle Driveやスキルを使うための設定
- 通信先、保存先、許可する操作を自分で決める作業

この入口を再現するには、公開コードのMac側を自分の環境へ合わせるだけでなく、Rokidの開発者向け作成画面で自分用の「私のAI」を登録し、必要な端末内処理を自分の責任で設計・検証する必要があります。公開リポジトリだけから実働版をそのまま作ることはできません。

開発初期の短期間だけ、アプリ一覧からAndroid版の「私のAI」を開く試作版がありました。公開コードに残るAndroid起動役と一時AIXの経路は、その試作版で各層を検証した参考実装です。一般利用者向けのインストール手順ではなく、Android開発とRokidの開発環境、実機検証ができる方を前提にしています。

具体的に置き換える箇所は [自分の環境へ合わせるための説明](docs/ADAPTATION.md) にまとめています。

動作保証や個別のセットアップサポートはありません。コードを読むだけでなく、自分の環境で安全性を確認してから使ってください。

## 主なフォルダ

- `daily-launcher-android/` — 開発初期の短期間だけ使ったAndroid起動役。端末とMacの開始・終了連携を読むための参考実装
- `daily-gateway/` — 会話、録音、Web・Obsidianの参照、保存前の確認をまとめる中心部分
- `mac-companion/` — Macのログイン後に、Rokidからの開始要求を待つ部分
- `aiui-knowledge-bridge/` — Rokidの画面、音声、Macとの受け渡しを扱う参考実装。実際に使っている「私のAI」のプログラムは含まない
- `knowledge-router/` — Obsidianから必要な文書を探し、回答へ渡す部分
- `action-candidate/` — 保存・編集前の確認と、確認した内容だけを1回実行するための共通部品

本仕様でも中心となるのは、`daily-gateway/`、`mac-companion/`、`aiui-knowledge-bridge/`の考え方です。実際に使っている「私のAI」と端末内の終了処理は、非公開の環境で管理しています。

主な節目は [CHANGELOG](CHANGELOG.md) で確認できます。

## 開発者向けの確認

Mac側の自動検査は、リポジトリの最上位で実行します。

```sh
npm test
npm run check
```

Android側の確認には、JDK 17、Android SDK 35、Gradleが必要です。Gradle wrapperと署名済みAPKは含めていません。

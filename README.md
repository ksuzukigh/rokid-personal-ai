# Rokid Personal AI（私のAI）

これは、**Rokid AI Glasses RV101に話しかけて、Mac上のAIと会話するために作ったもの**です。

眼鏡のマイクに話すと、Macが音声を文字にしてAIへ渡し、答えを眼鏡に表示します。前の話を覚えたまま会話を続けたり、Webや自分のObsidianを調べたりすることもできます。

このリポジトリは、完成品を配るためのものではありません。実際に動いている仕組みから個人情報や秘密の設定を取り除き、**同じようなものを自分で作りたい方が、設計とコードを参考にできる形**で公開しています。

## できること

- 眼鏡のマイクを使って、AIと日本語で会話する
- 前のやり取りを踏まえて、そのまま話を続ける
- Webを調べる
- 自分のObsidianにある文書を探し、内容をもとに答える
- 内容を確認してから、Obsidianに文書を作る
- 内容を確認してから、Obsidianの既存文書の一部を直す
- 内容を確認してから、指定したGoogle Driveフォルダに文書を作る
- スマートフォンのテザリングを使い、外出先でもMac上のAIと会話する

質問や調査は、普段の言葉で頼めます。「これは質問」「これは保存」といったメニューを先に選ぶ必要はありません。何を指しているのか分からないときは、AIが会話の中で聞き返します。

## 実際の使い方

1. Rokidのアプリ一覧から「私のAI」を開きます。
2. 「どうぞ」と表示されたら、テンプルを1回操作します。ここで録音が始まります。
3. 話し終わったら、もう一度操作します。
4. 眼鏡にAIの答えが表示されます。
5. 「続けて話す」を1回操作すると、前の会話を引き継いだまま次の録音が始まります。

アプリを開いただけでは録音しません。録音した音声と、文字起こしのために作った一時ファイルは、処理が終わると削除します。

## 保存や編集を頼んだとき

AIが勝手に文書を作ったり、書き換えたりすることはありません。

たとえば「この内容をObsidianへ保存して」と頼むと、眼鏡に次の内容が表示されます。

- 保存先
- 文書の題名
- 保存する本文
- 「まだ保存していません」という案内

内容を見て、別の1回操作をしたときだけ、その文書を1件作ります。取り消したとき、時間切れになったとき、確認後に内容や保存先が変わったときは、何も変更しません。

既存文書の編集やGoogleドキュメントの作成も、同じ手順です。文書を実際に保存・編集する直前は、人が内容を確認して決めます。

## 全体の仕組み

### 1. Rokid AI Glasses

利用者が話し、答えを読み、保存や編集の前に内容を確認する場所です。

↓　Wi-Fiまたはスマートフォンのテザリング

### 2. Mac

音声を文字にし、AIとの会話を続けます。必要に応じてWebやObsidianを調べます。

↓　保存や編集が必要な場合だけ、実行前の内容を眼鏡へ返す

### 3. Rokidで最終確認

対象と内容を読んで1回操作すると、その内容だけを実行します。取り消しや時間切れなら、何もしません。

個人資料をRokidへ保存するのではなく、Rokidは会話と確認、Macは音声認識、AIとのやり取り、資料の検索を担当します。

## このままでは使えません

このリポジトリには、次のものを入れていません。

- インストーラー
- インストール用APK
- GitHub Release
- 私が使っている通信先や認証情報
- ObsidianとGoogle Driveの実データ
- 録音、会話記録、実機画像
- 私のMacに合わせたパスや個人設定

つまり、ダウンロードしてボタンを押せば使えるアプリではありません。Rokid、Mac、通信経路、保存先を自分の環境に合わせて組み直し、自分で検証できる方を対象にしています。

この仕組みは、使う人ごとに資料、保存先、許可する操作が違います。そのため、共通のインストーラーは用意せず、設計とコードだけを公開しています。

## 自分で作ってみたい方へ

再現には、少なくとも次の環境と作業が必要です。

- Rokid AI Glasses RV101
- macOSを搭載したMac
- Node.jsとAndroidの開発環境
- ログイン済みのCodex CLI
- Macで動かすWhisperと音声判定モデル
- 自分で管理するHTTPS通信経路
- 自分のObsidian保管庫と、必要に応じてGoogle Drive
- 通信先、保存先、許可する操作を自分で決める作業

具体的に置き換える箇所は [自分の環境へ合わせるための説明](docs/ADAPTATION.md) にまとめています。

動作保証や個別のセットアップサポートはありません。コードを読むだけでなく、自分の環境で安全性を確認してから使ってください。

## 主なフォルダ

- `daily-launcher-android/` — Rokidのアプリ一覧から「私のAI」を開く部分
- `daily-gateway/` — 会話、録音、Web・Obsidianの参照、保存前の確認をまとめる中心部分
- `mac-companion/` — Macのログイン後に、Rokidからの開始要求を待つ部分
- `aiui-knowledge-bridge/` — Rokidの画面、音声、Macとの受け渡しを扱う部分
- `knowledge-router/` — Obsidianから必要な文書を探し、回答へ渡す部分
- `action-candidate/` — 保存前に内容を見せ、確認後に1回だけ実行する仕組みの原型
- `daily-app/` — 現在の形へ至る前に作った初期版

中心となるのは、`daily-launcher-android/`、`daily-gateway/`、`mac-companion/`です。ほかのフォルダには、機能を一つずつ試しながら現在の形へ発展させた過程も残しています。

主な節目は [CHANGELOG](CHANGELOG.md) で確認できます。

## 開発者向けの確認

Mac側の自動検査は、リポジトリの最上位で実行します。

```sh
npm test
npm run check
```

Android側の確認には、JDK 17、Android SDK 35、Gradleが必要です。Gradle wrapperと署名済みAPKは含めていません。

# Free-text Action Candidate

利用者の自由な日本語を、実行前の構造化候補へ変える部品です。固定コマンド表ではなく文全体をLunaが解釈します。

この部品には実行能力がありません。Obsidian書き込み、公開、送信、削除、購入、予定登録は行わず、返り値は常に`allowedNextStep: preview_only`、`executionCapability: none`、`changed: false`です。

## 安全境界

- ChatGPTログインのCodex CLIでGPT-5.6 Lunaを読み取り専用・一時セッションとして使う。
- APIキー関連の環境変数を除外し、コマンド、ファイル、Webなどの道具使用を検出したら失敗にする。
- 操作候補は影響の大小を問わず、必ず利用者確認を要求する。
- 公開・送信・削除・購入・予定登録は必ず高危険度として扱う。
- AIは保存先の絶対パスやURLを決められず、人向けの対象ヒントだけを返す。
- 曖昧な依頼は対象を推測せず、確認事項を最大3件返す。
- 入力本文は結果に再掲せず、照合用SHA-256だけを残す。

```sh
node action-candidate.mjs \
  --utterance "今日のRokid個人AIの実音声成功を、あとで振り返れるようにメモしておいて"
```

`dry-run-execution-adapter.mjs`は、Macが記録した確認済み候補だけを確認後15秒以内に一回受け、実行した場合の内容を模擬表示します。ファイル、通信、子処理の能力を読み込まず、成功・拒否のどちらでも`changed: false`、`protectedResourceChanged: false`、`sideEffectCount: 0`です。未確認、取消、期限切れ、確認後15秒超過、別候補、確認後の内容差し替え、二重模擬を拒否します。

確認ハッシュは候補ID、元発話ハッシュ、操作種類、対象範囲、危険度に加え、利用者が見た要約・対象ヒント・本文見本まで結び付けます。監査には確認秘密値と候補本文を残しません。実Obsidian追記や外部操作へは、まだ接続していません。

`prepare-candidate-preview-aix.mjs`は、Lunaが作った候補の種類・対象・内容または確認事項だけを、通信機能のない一時AIXへ埋め込みます。テンプル1回は「内容を確認した」という画面遷移だけで、確認要求や実行要求をどこにも送りません。

2026-08-23、RV101のYodaOS標準AIUIで一時AIXを直接表示し、利用者のテンプル1回で「内容を確認しました」へ変わることに実機合格しました。最初の画面は情報量が多かったため、実機入力合格後に5要素へ整理し、同じRV101で表示と確認後画面を再検査しました。録音、通信、保存、Agent登録、実行部品への接続はありません。

# AIUI自由発話→AI→RV101 検証経路

この文書の大部分は一回限定検証の履歴である。現在の利用者向けUIは、質問・依頼を区別せず`私：` / `AI：`で表示し、待機を「どうぞ」、継続を「続けて話す」とする。AIが必要なら利用者へ聞き返し、返答を同じCodex作業セッションへ戻す一般会話は実装済みである。現実作用候補は対象と内容と未実行状態を表示し、共通の確認・取消受け口だけへ渡す。機能別の実行URLはAIXへ戻さない。

段階3で合格したMac内の個人知識ルートを、録音なしのAIUIセッション指定質問とRV101短文表示へ一回だけ結合する検証。

実機合格した自由な言い方の例:

`ねえ、Rokidの個人AIづくり、今どこまで進んでいて次は何をするの？`

安全境界:

- RV101はセッション開始時に選んだ質問の送信、処理中・失敗・最終回答の表示だけを担当する。
- Mac受け口は`127.0.0.1`だけで待ち受ける。公開経路は試験中だけ開く。
- 32バイト以上の使い捨て認証、一回限り、2KB上限。質問はNFKC正規化後1〜240文字・改行なしとし、セッション開始時の一文と一致しない要求を拒否する。
- Lunaには質問だけ、その後Macが選んだ`allow`の抜粋最大6件・4,800文字だけを渡す。
- GPT-5.6 Luna、ChatGPTログイン、APIキー環境除外、読み取り専用、一時セッション。
- RV101へ返す回答は160文字以内。根拠IDはMacの監査結果に残す。
- 処理中の再操作、Back、画面終了では元通信を中断し、同じ要求IDの取消をMacへ送る。Macは実行中のCodex CLIを停止する。
- マイク、録音、音声認識、カメラ、Obsidian書き込み、実処理、Agent登録、クラウド公開は行わない。
- 一時AIX、使い捨て認証、公開経路、Mac受け口は成功・取消・失敗・期限切れのすべてで削除・停止する。RV101の実行キャッシュは通信機能のない同名AIXで上書きする。

ローカル検査:

```sh
npm test
```

一回セッション:

```sh
node start-session.mjs \
  "$HOME/Downloads/rokid-aiui-text-bridge.aix" \
  /tmp/rokid-aiui-knowledge-live.aix
```

2026-08-23のRV101実機では、この固定Tailscale FunnelはMac自己確認に合格したが、AIUI独自中継のTCP接続が10秒でタイムアウトした。既存の`cloudflared`で公開到達を確認してから作る一回Quick Tunnelでは完走した。

```sh
node start-cloudflare-session.mjs \
  "$HOME/Downloads/rokid-aiui-text-bridge.aix" \
  /tmp/rokid-aiui-knowledge-live.aix
```

Quick Tunnelは短命のランダムURLであり、この成功だけで日常利用の固定経路に採用しない。

2026-08-23の再診断では、Tailscale FunnelはMacからもTLS接続に失敗した。Cloudflare Quick Tunnelは別の切り分け試行でIPv4・IPv6のTLSと認証付き確認に合格したが、ランダム名で稼働保証がない。その後、個人AI専用ドメイン`example.com`に固定名`personal-ai.example.com`とnamed tunnel `rokid-personal-ai`を作成した。既存の`example.net`は変更していない。詳細は`../docs/fixed-transport-decision.md`を参照する。

固定経路の一回セッション:

```sh
ROKID_KNOWLEDGE_QUESTION="ねえ、Rokidの個人AIづくり、今どこまで進んでいて次は何をするの？" \
  node start-named-cloudflare-session.mjs \
  "$HOME/Downloads/rokid-aiui-text-bridge.aix" \
  /tmp/rokid-aiui-knowledge-live.aix
```

質問を指定しない場合は、過去の固定質問を互換用の既定値として使う。質問環境変数はCloudflare子処理とLuna子処理へ継承せず、Lunaには従来どおり質問プロンプトとして明示的に渡す。

Cloudflareの管理認証、トンネル認証、設定ファイルは`~/.cloudflared/`に置き、GitHubやAIXへ入れない。トンネルはセッション中だけ起動し、Macのログイン時には常駐させない。

Macから固定名の認証付き確認は合格。RV101 AIUIの初回試験は`personal-ai.example.com:443`のソケット接続が10.015秒で408タイムアウトとなった。DNS作成から30分後、接続確認モードは613msで成功し、続く固定質問は244msで接続、許可抜粋6件・2,908文字から作ったLuna回答をRV101実画面に表示した。成功後の台帳で行った再質問も、許可抜粋6件・2,749文字から現在の実機確認結果を回答した。接続情報なしAIXの再展開と全後片付けに合格した。

同日、セッション指定の自然な進捗質問を実機検証した。初回回答が古い`v0.1.0`を現在扱いしたため不採用とし、同日内の記録順、進捗質問での最新行優先、台帳全体で主体を確認して主語省略行を継続記録として扱う処理を追加した。修正後は許可抜粋2件・969文字から、24検査合格、Mac側の修正済み回答、次はRV101再表示という試験開始時点の状態をRV101へ正しく表示した。

## 自由発話入口の録音前準備

`voice-knowledge-relay.mjs`は、一回PCM受け口とMac内Whisperを使い、認識した1〜240文字・制御文字なしの自由質問を読み取り専用知識経路へ渡す。認証済み16kHz・モノラル・16bit PCM一件だけを受け、二件目、形式違い、1,920,000バイト超過、取消後の処理を拒否する。回答は160文字以内で、書き込みと外部操作は使わない。

2026-08-28からはwhisper.cppのSilero VADを常時有効にし、発話と判定された区間だけをWhisperへ渡す。現行VADモデルは`ggml-silero-v6.2.0.bin`、SHA-256は`2aa269b785eeb53a82983a20501ddf7c1d9c48e33ab63a41391ac6c9f7fb6987`。モデル本体はGitに含めない。完全無音と発話後の長い無音での定型句誤生成をMac合成音声で再現し、VAD有効後に消えることを確認した。特定の人名を常時ヒントまたは機械置換としては使わない。

`prepare-voice-aix.mjs`は、固定名`personal-ai.example.com`、短命認証、利用者による録音開始・終了、取消、AI発言表示を持つ一時AIXを作る。通常表示は「私のAI」「どうぞ」「聞いています」「考え中…」へ絞り、接続試行、録音バイト数、内部の処理段階は見せない。利用者が自分でアプリを開き、「どうぞ」でテンプルを1回操作すると録音を開始する。アプリを開いただけでは録音しない。無音時間による自動終了を使わず、話し終えたときのテンプル1回で確定する。AI発言後の「続けて話す」を1回操作すると、待機画面での追加操作を挟まず次の録音を開始し、同じCodex作業へ戻す。AIの実行候補は会話の一部として対象・内容と「まだ実行していません」を示し、余分な確認準備画面を挟まない。文字化した利用者の発言とAIの発言はObsidianの日付別会話記録へ自動追記し、原音と一時WAVは処理後に削除する。生成AIXと認証はGitHubへ入れない。

固定名自由発話セッションの準備コマンド:

```sh
node start-named-voice-session.mjs /tmp/rokid-aiui-voice-knowledge-live.aix
```

このコマンドは、Mac受け口と固定Cloudflare経路の認証付き公開確認が成功した後だけ一時AIXを作る。終了・取消・失敗・期限切れでは受け口、トンネル、Mac側一時AIXを停止・削除する。録音はRokid上の「どうぞ」でテンプルを1回操作した時に始め、チャットで別の録音許可は求めない。

2026-08-23、まず録音せずMac合成音声一件で入口以降を検査した。5.75秒相当・184,146バイトのPCMをMac内Whisperへ渡した初回は`個人AIづくり`を`個人合作り`と認識したため、回答経路が完走しても文字起こし精度は不採用とした。既存の限定用語辞書へこの一組だけを追加し、同じPCMで`個人AIづくり`を正しく文字化。Luna二段階とObsidian許可抜粋から15.989秒で、当時の33検査と次の実機確認を160文字以内で正しく回答した。その後、録音画面・PCM受け口・文字起こしコードと用語辞書をこのリポジトリへ取り込み、全35検査に合格した。合成音声・PCM・ログは試験後にMacのゴミ箱へ移動した。

同日の録音なし固定名事前検査では、Mac受け口起動後にnamed tunnelが4接続を確立し、認証付き`/v1/health`は3回目・1.498秒で成功した。その後だけ一回認証入りAIXを作成し、SHA-256は`d7872ee4383b23d2ac34ad0c4ea392c35d9e0eb0afe71e0019ca1c9fdf40c833`。RV101へ配置せず停止し、一時AIXなし、18448番の待受なし、関連`cloudflared`なし、トンネル有効接続0を確認した。録音、Whisper、Luna、Obsidian読み取り・書き込みは使っていない。

その後、新しい一回録音同意で、案内した自然な進捗質問を利用者がRV101へ発話した。二段階開始後の録音は9.7秒、310,400バイトで10秒上限により停止し、一回だけ受理。Mac内Whisper、Luna二段階、Obsidian許可抜粋、RV101回答表示まで19.723秒で完走し、利用者が物理操作と回答表示を確認した。回答画像SHA-256は`6b22335f151265cc180c0ea7868740ab310d98e66ab7aa0cfbb19004ae51503a`。原音と一時WAVは0件、一時AIXと受け口を削除・停止し、RV101の同名実行キャッシュを接続情報なし版へ再展開、遠隔AIX削除、消灯5秒復元を確認した。認識全文は保存しない設計のため厳密な文字列照合、900ms無音停止、複数の言い換え、騒音下は未確認。Obsidian書き込みと外部操作は行っていない。この録音同意は使い切りである。

続く録音なしのLuna検査では、同じ意図を3種類に言い換えた。最初は台帳の最新「証拠保存」行だけが選ばれ、直前の実機成功を落として未確認と誤答したため不採用。現在質問では保存・監査行と直前の実体記録を一組にし、`Rokidシステム化/README.md`の「現在の結論」を途中記録より優先、解消済み課題を次工程へ戻さない規則を追加した。修正後は3問すべて、実機合格、未確認範囲、次工程を正しく回答した。GPT-5.6 Luna、ChatGPTログイン、読み取り専用、一時セッション、道具使用0、API環境除外で実行。全37検査に合格した。

さらに「最初の方式から今日の実音声成功まで」を時系列質問として分離した。同じ台帳から複数時点を残し、証拠保存だけの行を段階から外し、実音声成功を終点に指定した質問では利用者発話またはRokidマイクの実体記録を必ず含める。最終の録音なしLuna検査は、初期AIUI／Mac分業、Obsidian許可抜粋、固定質問、合成音声、人声・Rokidマイク・RV101表示19.723秒を正しい順で回答し、確信度high。全38検査に合格した。

Lunaを呼ばず固定名の実機到達だけを再確認する場合は、次の接続確認モードを使う。

```sh
ROKID_KNOWLEDGE_HEALTH_ONLY=1 node start-named-cloudflare-session.mjs \
  "$HOME/Downloads/rokid-aiui-text-bridge.aix" \
  /tmp/rokid-aiui-knowledge-health.aix
```

`SESSION_READY`後だけ一時AIXをRV101へ配置する。受信完了または期限切れ後、Mac側AIXと公開経路は自動で消える。RV101側の一時AIXは別途削除する。
